How it works — the pipeline

1Input — georeferenced drone/aerial image (GeoTIFF, 1 m, EPSG:3035)
2Preprocess — tile large orthomosaics, normalize
3Bund detection — a model predicts the field boundaries
4Parcel extraction — group boundaries into individual closed fields
5Vectorize + georeference — pixels → Shapely polygons → real GPS
6Area — exact hectares & acres (equal-area projection)
7Overlay + export — PNG overlay + GeoJSON / GeoPackage / CSV

Done ✅

  • Full pipeline working end-to-end on real data
  • We trained our own model — multi-task U-Net (extent + boundary)
  • Integrated Delineate Anything v2 — SOTA field model
  • Live web demo (Streamlit) with a detector toggle, runs offline
  • GIS exports — GeoJSON, GeoPackage, CSV, overlay PNG
  • Pitch materials — architecture page + 7-minute jury script

In progress 🚧

  • SAM 3 (Meta) — access requested, awaiting approval
  • Sharper accuracy — more epochs / boundary-weighted loss
  • Robustness pass — graceful handling of empty tiles (done) & edge cases

The future — where this goes next

A clear path from a working prototype to a deployable land-mapping product.

Near term

  • SAM 3 as a third detector once Meta approves access — a full foundation-model comparison
  • Higher accuracy — more training epochs + a boundary-weighted (Tversky) loss to catch faint internal bunds
  • Interactive GPS map (Leaflet) inside the web app
  • Batch mode — process a whole orthomosaic and aggregate every field

Beyond

  • India-specific imagery — retrain on paddy fields for local deployment
  • Scale to regions / satellite — Delineate Anything already maps at country scale
  • Land-records integration — an API + export straight into government GIS systems
  • Field-ready app — run from a drone operator's laptop on-site
  • Change monitoring — compare seasons to track land-use change & disputes

What we use — and why

Every major choice, with the reason behind it. Nothing here is arbitrary.

What we useWhy we use it
Dataset
AI4Boundaries		Real, labelled EU farm parcels — gives us the bund target and a ground-truth metric with zero manual labelling.
Projection
EPSG:3035 (equal-area)		Because it's equal-area, hectares and acres come out geometrically exact, not estimated.
Our model
U-Net + ResNet-34		The proven architecture for boundary segmentation; ImageNet-pretrained means high accuracy from little data, and it's light enough to run on a laptop.
Our model
Multi-task (extent + boundary)		Predicting the field mask too excludes roads/forest, gives cleaner parcels, and yields a strong headline metric (extent IoU 0.65). It's the published best practice for this data.
Post-processing
Watershed (scikit-image)		Bunds are thin and broken; watershed floods each field across the gaps to form whole, closed parcels — where naive methods fail.
Best model
Delineate Anything v2		Purpose-built SOTA for field boundaries (73M fields, 61 countries). Outputs parcels directly (no watershed), 125 MB, runs on a laptop, and is openly available — no gating.
Inference engine
Ultralytics (YOLOv11)		Runs Delineate Anything efficiently — fast, lightweight instance segmentation.
Geospatial
rasterio · shapely · geopandas · pyproj		The standard geospatial stack — turns pixels → GPS polygons → exact area, and exports every GIS format.
Deep learning
PyTorch · segmentation-models-pytorch		Industry-standard training + a library of pretrained segmentation backbones, so we build on proven models instead of from scratch.
Web demo
Streamlit		The fastest path to a live, clickable demo the jury can watch — and it runs fully offline.
Compute
Kaggle T4 → laptop		A free 16 GB GPU to train; then inference runs on the laptop so the demo needs no internet.
Planned
SAM 3 (Meta)		An open-vocabulary foundation model that could give the sharpest boundaries — a future upgrade (access pending approval).
Bottom line: the system works end-to-end on real data today — we trained our own model, integrated the state-of-the-art field model, and every field comes out as a GPS-mapped parcel with exact area, exportable to any GIS. TechVortex '26.
